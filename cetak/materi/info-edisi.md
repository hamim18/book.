# Informasi Edisi dan Kanal Koreksi

Edisi cetak pribadi pertama — Oktober 2026.

Diterjemahkan dari *The Rust Programming Language* edisi 2024 (versi daring),
yang mengasumsikan Rust 1.98.0 atau lebih baru dengan `edition = "2024"`.

**Kanal koreksi**

Catatan koreksi — kesalahan ketik, saran terjemahan, atau koreksi teknis —
dapat ditambahkan ke berkas `ROADMAP.md` pada repositori proyek terjemahan
ini.

Buku ini dicetak untuk pembelajaran pribadi dan tidak diperjualbelikan.
